# 推广中心 V1 界面规范

适用于本模块；验证可用后再作为其他重构模块的基础。原型：`promotion_center_v1/prototype/index.html`。

## 原则

1. **先回答“我现在要做什么”**：工作台只列需要处理的事项和异常，不堆统计图。
2. **一个状态，一个主按钮**：每个推广只显示一个状态标签；页面右上角只有一个深色主按钮，危险操作单独用红色描边按钮。
3. **状态说人话**：失败、跳过、不确定都要写原因；“结果不确定”和“发送失败”分开显示。
4. **所见即所发**：编辑时右侧实时显示按真实客户渲染的邮件；审批人看到的是同一份冻结内容。
5. **不能做的事不显示按钮**：角色或状态不允许的操作直接不出现；页面级无权限时显示原因。
6. **确认框写清后果**：说明影响多少对象、能否撤销，例如“已交给邮件服务器的邮件无法撤回”。

## 视觉变量

| 变量 | 值 | 用途 |
|---|---|---|
| 背景 | `#f6f5f2` | 页面底色（暖灰，区别于卡片白） |
| 卡片 | `#ffffff`，圆角 12px，细阴影 | 内容分区 |
| 主文字 / 次文字 / 弱文字 | `#1d1b18` / `#4a4640` / `#807a71` | 三级文字层次 |
| 主按钮 | 墨黑 `#1d1b18` | 每页唯一的主操作；导航选中态 |
| 强调色 | `#3b4fd8` | 链接、焦点、变量、进行中状态 |
| 成功 / 警告 / 危险 | `#19794b` / `#a35c00` / `#b3261e`，各配浅底色 | 状态标签与进度条 |

| 间距 | 4 的倍数：卡片内边距 16–18px，卡片间距 16px | |

## 组件

- **状态标签**：圆点 + 文字，浅底色；九种推广状态与七种对象状态的配色固定（见 `DESIGN.md` 第 5 节）。
- **进度条**：绿色已发送、红色失败、橙色不确定叠加显示，下方写具体数字。
- **分段筛选**：列表顶部的状态与来源筛选，用分段按钮而不是下拉框。
- **选项卡片**：互斥的方式选择（推广方式、发件规则）用卡片，每张写一句后果说明。
- **底部检查栏**：编辑页固定在底部，列出全部检查项、是否需要审批及原因、操作按钮；检查未通过时主按钮禁用。
- **横幅**：页面顶部的提示，蓝色说明、橙色等待、红色退回或异常。
- **弹窗**：标题 + 后果说明 + 必填项校验（错误显示在弹窗内，不关闭弹窗）；Esc 和点击遮罩关闭。

## 响应式

- 1100px 以下：编辑页预览移到表单下方，双栏改单栏。
- 760px 以下：侧栏改为顶部横向导航，底部检查栏换行，表格可横向滚动。
- 遵循“减少动态效果”系统设置，动画仅 140ms 淡入。
