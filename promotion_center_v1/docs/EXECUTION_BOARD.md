# 推广中心 V1：执行看板

一场推广开始后（或跑完后）看执行情况的独立页面：发了多少、谁没发出去、线下还剩什么、哪个邮箱出问题，一页看全，不用逐条翻明细。

原型：`prototype/index.html#/board`（指定场次：`#/board/<推广编号>`）。

## 1. 入口

| 位置 | 说明 |
|---|---|
| 左侧导航「执行看板」 | 独立页面，默认打开一场（见第 2 节），页内可切换场次 |
| 推广详情顶部「查看执行」 | 直接进入该场看板 |
| 推广列表每行「查看执行」 | 已开始、已排期、已结束的推广显示 |
| 门户「推广中心」卡片标签 | 增加“执行看板”。门户入口仍指向旧 `promotion.php`，第 5 阶段切换后指向本模块 |

## 2. 场次

- 下拉按“进行中 / 已排期 / 已结束 / 未开始”分组，只列当前用户能看的推广（`get_user_scope('promotion')`）。
- 默认：发送中且开始时间最近的一场；没有发送中的，取最近开始、有执行数据的一场。
- 草稿、待审批、已退回、已取消的推广显示场次摘要和空状态“还没有执行数据”，并写明原因。

## 3. 区块与口径

| 区块 | 内容 | 口径 |
|---|---|---|
| 场次摘要 | 名称、状态、创建人、时间范围、发送时间方式、发信方式 | 时间范围 = 计划首封 → 计划末封（含顺延），另显示最后一封实际发出时间 |
| 总进度 | 邮件已发 / 待发 / 失败 / 跳过；线下已完成 / 未完成（含逾期）；完成率 | 待发 = 待发 + 额度顺延 + 邮箱暂停 + 推广暂停；失败 = 发送失败 + 结果不确定；跳过 = 冻结时判定发不了的邮件对象与线下对象；完成率 =（邮件已发 + 线下已完成）÷（邮件对象 + 线下待办）。偏好里没勾邮件、改走线下的不算跳过 |
| 发不了 / 异常 | 每条：类型、客户、联系人与邮箱（或号码、群）、渠道、原因、负责人；上方按原因汇总，可点原因筛选 | 类型按顺序排：发送失败、结果不确定、邮箱暂停、额度顺延、线下逾期、发不了。发不了的原因与新建向导一致（`CREATE_FLOW.md` 2.7） |
| 发送时间线 | 按计划时间（北京时间）逐封列出，按日分段；客户当地时间、发件邮箱、状态、实际发出时间 | 顺延的显示原定日期；额度预警标黄，失败与邮箱暂停标红 |
| 发信箱 | 每个邮箱：本场分配、已发、失败、待发；当日用量条；状态 | 状态：登录失败已暂停 / 触顶日额度·顺延 N 封 / 接近日额度（用量 ≥ 预警比例，默认 80%） / 正常。当日用量包含该邮箱的日常发信 |
| 线下执行 | 按渠道（微信、微信群、WhatsApp、电话）：待办、已完成、逾期、发不了；执行明细列表 | 点一行看执行人、渠道、联系方式或群（含群里客户）、截止、状态与结果、完成时间、截图 |
| 效果粗览 | 打开、点击、退订、意向 | 意向 = 邮件回复 + 线下结果“有意向”。打开、点击需要开启追踪（`DESIGN.md` 第 13 节第 2 项）；未开启时只显示退订和意向。详细分析留在“效果分析” |

## 4. 筛选

| 筛选 | 发不了 / 异常 | 发送时间线 | 线下明细 |
|---|---|---|---|
| 全部 | 全部 | 全部邮件 | 全部 |
| 仅异常 | 全部 | 失败、不确定、邮箱暂停、顺延、额度预警 | 逾期 |
| 仅线下未清 | 线下发不了与逾期 | 不显示 | 未完成 |
| 仅失败 | 失败与不确定 | 失败与不确定 | 结果为“无法联系” |

原因筛选可与以上叠加；切换场次时清除。

## 5. 权限与范围

- 能进推广中心（`promotion.view`）即可看；场次范围同推广列表。
- 业务员看不是自己创建的推广时，只显示自己负责的客户和分给自己的线下待办，页面顶部提示。
- CRM 历史推广只读显示；暂停、继续、登记结果在 CRM 中操作。
- 看板只读。处理动作在原位置完成：核对“结果不确定”在推广详情，登记线下结果在人工待办，邮箱密码在原邮箱系统。

## 6. 数据来源（正式实现）

| 内容 | 来源 |
|---|---|
| 名单与发不了原因 | `pm_campaign_audience`（提交时冻结，含原因代码） |
| 计划时间、顺延、发件邮箱、发送状态 | `pm_deliveries`，状态从 `crm_mail_send_jobs` 回读（success / failed / unknown / cancelled） |
| 失败原因 | 原邮箱系统任务的错误信息（退信码、SMTP 错误） |
| 邮箱当日用量 | 原邮箱系统当天已发数量（含日常发信） |
| 线下执行 | `pm_manual_tasks`（执行人、结果、截图、完成时间） |
| 退订、回复 | 联系人 `unsubscribe_email` 变更记录；邮箱系统 IMAP 收到的回信按邮件头关联 |
| CRM 历史 | `LegacyCrmPromotionAdapter` 只读 |

发送中的场次每 60 秒刷新一次数字，不整页重载。

## 7. 待确认

2. 是否需要打开、点击追踪（同 `DESIGN.md` 第 13 节第 2 项）。
3. 看板是否需要导出（目前导出在推广详情的收件对象）。
