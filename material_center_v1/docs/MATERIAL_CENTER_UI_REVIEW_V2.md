# Material Center UI Review V2

## A0 审计结论

- 范围仅限 `material_center_v1`；旧广州页面和旧表不在修改范围。
- 原侧栏仅覆盖少量电源页面，缺少主数据、供应商、替代、接入、文档与设置入口。
- 原抽屉为 820px，短字段浪费横向空间。
- 原表格页面固定最大宽度、固定每页20条，无法利用可视高度。
- 原分页缺少自动行数、30/100条、首末页省略和视口重算。
- 现有统一组件和 InteractionManager 可继续复用，无需建立第二套。

## 已修复

A1 完整分组菜单、白色框架和未配置页；A2 统一视觉不新增重复组件；A3 标准化抽屉默认520px、范围460–620px、拖动记忆、小屏全屏；A4 表格全宽全高、内部滚动、自动分页；A5 列显示、列宽、双击适配、列拖动和个人视图记忆基础。
