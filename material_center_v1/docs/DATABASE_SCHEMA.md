# 物料中心数据库说明

所有新增业务表均使用 `mc_` 前缀。迁移位于 `database/migrations/`，通过 `php tools/migrate.php up` 或 `php tools/migrate.php down <version>` 执行。

## 迁移

- `001–004`：电源试点、字段/批量/生命周期、设置和权限基础。
- `005`：主数据完整领域、来源/导入、供应商、适配、替代、文档版本、设置版本和审批。
- `006`：七类物料及字段注册。
- `007`：供应商档案扩展。
- `008`：供应商价格审批状态与索引。
- `009–011`：类别字段映射、七类完整字段和数值范围校验。
- `012`：供应商版本化附件及访问元数据。

每个迁移均含 `down`。`010–012` 已在服务器实际执行回滚和重迁移。

## 领域

- 主数据：`mc_materials`、`mc_material_categories`、`mc_material_metadata`、七类扩展表、字段注册/选项/映射。
- 生命周期：审批、事件、版本、批量任务、活动、修改和操作日志。
- BOM 接入：`mc_source_records`、`mc_source_mappings`、`mc_legacy_links`；旧 `bom_materials` 无 DDL/DML。
- 导入：`mc_import_tasks`、`mc_import_rows`、`mc_import_errors`；覆盖物料和供应商价格任务。
- 供应商：档案、联系人、供应商物料、价格/历史/阶梯、MOQ、交期和 `mc_supplier_documents`。
- 产品适配：产品快照、配置组、选项、条件、默认、冲突、审批和日志。
- 替代：替代关系、引用迁移批次、版本和精确回滚。
- 文档/设置/权限：物料文档版本、设置版本、权限、授权、字段规则和审计。

业务唯一键、状态索引、来源哈希、乐观锁和批次 UUID 均由迁移与服务层共同约束。正式物料不物理删除；仅无引用草稿允许删除。
