# 物料中心数据库说明

所有新增业务表均使用 `mc_` 前缀，迁移位于 `database/migrations/`，由 `bin/migrate.php up|down` 执行。

## 领域

- 主数据：`mc_materials`、`mc_material_categories`、`mc_material_metadata`、七类扩展表、字段注册与选项表。
- 生命周期：审批、生命周期事件、版本、活动及操作日志。
- 旧 BOM 接入：`mc_source_records`、`mc_source_mappings`、`mc_legacy_links`。旧 `bom_materials` 仅 SELECT。
- 导入：任务、行、错误；确认执行使用事务。
- 供应商：供应商档案、联系人、供应商物料、当前价、价格历史、阶梯价、MOQ、交期及附件。
- 产品适配：旧命名产品快照、配置组、选项、条件、默认、冲突、审批及日志。
- 替代：替代关系、引用迁移批次和物料版本；引用迁移仅更新 `mc_` 表。
- 文档/设置/权限：文档版本、设置版本、权限、授权及审计。

## 完整性约束

业务唯一键、防重复键、状态索引及来源哈希定义在迁移中。物料物理删除仅允许无引用草稿；正式数据采用生命周期状态。旧表无新增字段、触发器或外键。
