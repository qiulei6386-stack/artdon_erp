# 物料领域模型（当前只读阶段）

当前可确认的物料只读视图包含：

- 源 ID
- 分类
- 名称
- 品牌
- 型号
- 规格
- 单位
- 材料牌号
- 图片路径
- 有效状态
- 更新时间

## MM2 正式结构

`mc_materials` 使用自增永久 ID 和独立 UUID，物料编号唯一；品牌与型号仅用于检索和重复候选，不作为主键。

正式结构已覆盖分类、动态属性、供应商物料与 DECIMAL 价格、替代料、文档、版本、旧源链接和活动日志。删除采用 `deleted_at` 软删除。

试点电源建立后默认：

- `status=draft`
- `is_pilot=1`
- `allow_bom=0`
- `allow_quote=0`
- `allow_customer_display=0`

因此试点不会自动进入 BOM、报价或客户展示。
