> **用途**：现有物料中心整站外壳已经完成。本文件用于让 Codex 在不推翻现有界面、不改变左侧菜单、不重写视觉体系的前提下，一次性接入数据库、业务逻辑、权限、联动、测试和交付。

# 1. 最终目标

把现有“物料中心整站外壳”接成可正式使用的物料主数据系统，并最终成为以下业务的统一物料来源：

```text
旧 BOM 共享物料数据
          ↓ 只读接入
物料中心暂存、解析、标准化
          ↓
物料正式库
          ↓
产品适配
          ↓
BOM / PLM / 报价 / 采购 / 库存 / 新加坡下单站
```

必须实现：

1. 所有菜单页面使用真实数据；
2. 物料可新增、编辑、复制新增、导入、确认、转正式、停用、归档；
3. 旧 BOM 数据只读接入，不修改旧表；
4. 电源、芯片、光学、型材、接头、配件、包装各自拥有类别字段；
5. 支持供应商、价格、MOQ、交期和价格历史；
6. 支持产品与物料适配规则；
7. 支持替代物料、版本和停产替换；
8. 支持文件、图片、规格书、认证资料；
9. 支持统一账号、角色、权限、操作日志；
10. 所有页面具备真实搜索、筛选、分页、抽屉、批量处理和错误反馈。

# 2. 硬性限制

## 2.1 左侧菜单不能改

必须保持当前菜单：

```text
工作台

物料库
├── 全部物料
├── 电源
├── 芯片
├── 光学
├── 型材 / 散热件
├── 接头 / 安装件
├── 配件
└── 包装

业务
├── 产品适配
├── 供应商与价格
├── 替代与版本
├── 数据接入
└── 文档与日志

系统
└── 系统与设置
```

不得新增“来源数据、标准化、功率档、重复记录”等左侧菜单。这些功能只能放在页面 Tab、筛选抽屉、详情抽屉、更多菜单或系统设置中。

## 2.2 不得重新设计现有外壳

保留现有：

- 左侧导航；
- 顶部栏；
- 白色 / 浅灰视觉；
- 青绿色主操作色；
- 页面边距；
- 字号层级；
- 表格风格；
- 抽屉、弹窗、Toast 体系。

只允许修复布局、补齐交互、增加字段、优化响应式和提升可用性。

## 2.3 旧 BOM 只读

禁止对旧 BOM 物料表执行：

```text
ALTER / DROP / TRUNCATE / RENAME / UPDATE / DELETE / INSERT
```

所有写入进入 `mc_*` 表。

## 2.4 不建立第二套账号

必须复用广州 ERP 现有 Session、用户 ID、姓名、部门、角色和权限。若缺少物料中心权限项，只新增模块权限配置，不新建用户密码系统。

## 2.5 正式物料不得物理删除

- 未引用草稿可删除；
- 正式物料只能停用、归档、替代、合并；
- 删除、停用、归档前必须检查 BOM、产品适配、报价、库存、订单、供应商价格等引用；
- 被引用时显示引用位置和数量。

# 3. 固定页面与交互标准

## 3.1 工作台

接入真实：

- 待整理数量；
- 待确认数量；
- 适配冲突；
- 供应商价格变化；
- 最近新增和修改；
- BOM 来源同步；
- 待审批事项。

快速入口必须跳到真实页面，不保留长期演示数据。

## 3.2 物料列表页

适用于全部物料、电源、芯片、光学、型材、接头、配件、包装。

顶部保持压缩，不增加大型数字看板。固定 Tab：

```text
全部 | 待整理 | 待确认 | 正式 | 异常
```

说明：

- 来源数据不是 Tab；
- 重复候选不是 Tab；
- 停用 / 归档不是 Tab；
- 来源、重复、停用、归档进入筛选抽屉；
- 旧 `tab=source` 等参数要兼容并转换为筛选条件。

默认工具栏：

```text
搜索 | 筛选 | 更多 | 视图设置 | 刷新
```

未选中数据时不显示批量按钮。选中后显示：

```text
已选择 N 项 | 批量设置 | 批量分类 | 转正式/停用 | 导出所选 | 取消选择
```

## 3.3 表格

必须实现：

- 服务端搜索、筛选、分页；
- 表头固定、分页固定、数据区独立滚动；
- 自适应分页；
- 左复选框和右操作列冻结；
- 列宽拖动、双击自动适配；
- 显示 / 隐藏列、列顺序保存；
- 用户视图保存；
- 舒适 / 标准 / 紧凑行高；
- 当前页多选和全部筛选结果选择；
- Excel 多行复制粘贴；
- 批量清空、查找替换；
- 撤销 / 重做；
- 键盘导航；
- 错误单元格定位。

分页：

```text
Auto / 10 / 20 / 30 / 50 / 100
```

Auto 根据可用高度、行高、浏览器缩放、侧栏折叠、抽屉、字号和窗口变化动态计算，使用 `ResizeObserver`。

## 3.4 详情抽屉

默认 520px，最小 460px，最大 620px；支持拖动调宽并记忆；移动端全屏。

支持：

- 查看；
- 编辑；
- 保存；
- 保存并下一条；
- 复制新增；
- 停用；
- 归档；
- 查看引用；
- 修改日志。

头部固定、正文滚动、底部固定；未保存关闭必须确认。

## 3.5 批量设置

动态添加字段，字段来自字段注册中心。支持：

```text
只填空值
覆盖已有值
条件覆盖
仅覆盖待确认值
仅覆盖低置信度值
```

执行前预览选中数量、实际影响数量、原值、新值、冲突和跳过原因。执行后返回成功、跳过、失败、失败明细、操作日志和可回滚批次号。

必须区分：

```text
选择当前页
选择全部筛选结果
```

## 3.6 产品适配

保持三栏：

```text
产品列表 | 配置规则 | 选项详情
```

配置组：

- 芯片 / 光源；
- 电源 / 驱动；
- 调光方式；
- 光学 / 透镜；
- 附件配件；
- 外观颜色；
- 安装方式；
- 特殊要求；
- 自定义配置组。

右栏 Tab：

```text
选项列表 | 默认设置 | 替代关系 | 适用条件 | 价格影响 | 审批设置
```

复杂适配规则归物料中心维护，商务中心只读取已批准结果。

# 5. 分类字段

## 5.1 电源（最高优先级）

基础：名称、品牌、型号、供应商型号、来源、状态、供应商、供应商质保、MOQ、采购价、币种、交期。

电气：

```text
额定功率
最大输出功率
功率档
输入电压最小/最大
输入频率
输出类型：恒流 / 恒压
输出电流
输出电流最小/最大
拨码电流列表
输出电压最小/最大
PF
效率
调光方式
认证
防护等级
```

结构：

```text
安装方式：内置 / 外置 / 远置 / 一体式 / 轨道式 / 接线盒 / 未知
长度 / 宽度 / 高度 / 直径 / 开孔
外壳材质 / 颜色
```

功率档：

```text
1–3W / 3–5W / 5–8W / 8–15W / 15–20W / 20–25W / 25–35W / 35–50W
```

边界采用 `[min,max)`，最后一档可闭合。供应商质保为 3 年、5 年、其他、待确认；不得与客户整灯质保混用。

## 5.2 芯片

品牌、型号、封装、光源类型、额定/最大功率、电压、电流、色温、显指、光通量、光效、SDCM、R9、尺寸、焊盘、寿命、认证。

## 5.3 光学

类型、品牌、型号、适配芯片、直径、高度、角度、角度范围、材质、透光率、光型、颜色、安装结构、IES / 配光文件。

## 5.4 型材 / 散热件

类型、材料牌号、长宽高、直径、重量、散热能力、表面处理、颜色、加工状态、图纸版本、供应商。

## 5.5 接头 / 安装件

类别、系统类型、电气规格、安装方式、接口、颜色、尺寸、承重、材质、防护等级、适配产品。

## 5.6 配件

配件类别、型号、尺寸、颜色、材质、安装位置、适配产品、适配光学、价格影响、客户是否可选。

类别包括蜂巢网、透明玻璃、柔光玻璃、滤色片、四叶片、防眩圈、装饰环和其他。

## 5.7 包装

包装类别、型号、内外尺寸、材料、克重、印刷方式、颜色、装箱数量、净重、毛重、客户专属、刀模图、标签模板。

# 6. BOM 来源和标准化

建议表：

```text
mc_source_records
mc_source_mappings
mc_import_tasks
mc_import_rows
mc_import_errors
```

流程：

```text
读取旧 BOM → 保存来源快照 → 字段解析 → 匹配正式物料 → 重复判断 → 置信度 → 待整理/待确认 → 人工确认 → 正式物料
```

不得静默覆盖正式物料。来源必须保留原始文本、来源表、来源主键、读取时间、解析结果、置信度、映射正式物料、确认人和确认时间。

重复判断：

```text
精确重复 / 高概率重复 / 可能重复 / 型号冲突 / 规格冲突
```

# 11. Codex 连续执行纪律

1. 先读完整文件；
2. 不要只完成第一步；
3. 不要每做一个按钮就询问；
4. 按 10 步连续执行；
5. 每步完成后运行测试；
6. 测试失败先自行修复；
7. 不得隐藏错误；
8. 不得用静态假数据冒充完成；
9. 不得删除现有可用页面；
10. 不得大规模重写 UI；
11. 不得修改旧 BOM；
12. 不得建立第二套登录；
13. 数据库变更必须有迁移和回滚；
14. 写操作必须事务处理；
15. 批量操作必须有失败明细；
16. 所有变化写执行日志；
17. 可整理公共代码，但必须保持路由兼容；
18. 旧 URL 保留或兼容跳转；
19. 非阻断问题写入 `KNOWN_ISSUES.md` 后继续；
20. 只有权限、数据库或关键来源完全不可用时才停止。
