# UI 决策记录

1. UI 基础设施全部放在 `material_center_v1/ui/`，页面专属样式保留在模块自身 `assets/`。
2. 主题以 `data-theme` 控制并存入 `localStorage`，默认跟随系统。
3. 下拉、弹窗和抽屉统一由 InteractionManager 控制；同一时间仅允许一个浮层打开。
4. 当前系统保持只读，不新增写操作，不修改数据库结构。
5. 首页表格采用前端 20 条分页，后端既有读取边界不变。
6. 组件展厅位于 `ui/docs/component-gallery.php`，与业务页面使用同一套真实组件。
7. 表格排序、选择、列宽、列显示、密度和分页均由唯一 `ui/js/table.js` 渐进增强；无 JavaScript 时仍保留服务端只读表格内容。
8. Modal 尺寸严格限定 S 480、M 640、L 800；电源详情使用 M 520 Drawer。
9. 未接入按钮统一显示“该功能尚未接入”，不模拟保存成功。
10. 电源只读识别采用旧源 `category/name` 的“电源/驱动”关键词，仅用于发现，不定义正式迁移模型。
11. F1 默认采用白色侧栏；深色仍作为可选主题，不复制组件样式。
12. 设置只注入经过服务端白名单校验的 CSS 变量，禁止任意 CSS。
13. 侧栏分组使用可访问的 `details/summary`；临时菜单和浮层仍由 InteractionManager 独占控制。
14. 主内容取消1500px最大宽度，横向滚动仅允许发生在表格容器。
15. 自动分页基于真实正文可用高度，不根据屏幕分辨率写死。
