# 电源工作台 UI 纠偏基线

更新时间：2026-07-25

## 安全基线

- 修改范围仅限 `material_center_v1`。
- 后端服务、适配器、数据库、权限、旧页面与旧路由全部保留。
- 广州旧 BOM 仅通过现有只读仓储查询，不写入、不改表。
- 本轮暂停新增电源业务能力。

## 纠偏前基线

- 可见 Tab 7 个：全部、来源数据、待整理、待确认、正式、重复候选、停用/归档。
- 顶部统计大卡片 4 个。
- 行操作按来源重复显示“进入标准化”或“管理”。
- 页面使用通用表格组件，但未锁定为工作台全高布局。
- 旧入口包括工作台旧 Tab、源数据页、标准化页、正式库及功率档页。

## 纠偏检查点

- 可见 Tab 锁定为 5 个，统计大卡片为 0。
- 来源、重复、停用、归档由筛选承接。
- 表格正文 13px、标准行高 44px；数据区滚动，分页固定容器底部。
- 抽屉默认 520px、限制 460–620px，并沿用统一交互管理器。
