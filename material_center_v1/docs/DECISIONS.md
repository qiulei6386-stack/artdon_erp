# 物料中心决策记录

1. 新中心保持 sidecar 模式，复用旧 ERP 登录与数据库连接。
2. `bom_materials` 只读；仓库层拒绝非 `SELECT`。
3. 所有 UI 能力集中在 `material_center_v1/ui/`，页面专属行为留在模块 `assets/`。
4. Modal 仅提供 S 480、M 640、L 800；复杂详情使用右侧 Drawer。
5. 电源先采用旧源关键词只读发现，不视为正式迁移。
6. 表格增强在浏览器端完成，不改变后端读取边界和旧表。
7. 所有新表以 `mc_` 开头；迁移通过 `mc_schema_migrations` 记录，提供反向删除顺序。
8. `LegacyBomMaterialAdapter` 是旧 `bom_materials` 的唯一 MM4 读取入口并拒绝非 SELECT。
9. 解析器只产出未确认候选；高可信候选也不会自动转为正式数据。
10. 功率档从数据库边界建议，允许后台维护和人工更正。
11. 20–25W 试点范围采用正式边界 `20 ≤ P < 25`。
12. 因旧文本未明确输出类型，本轮不代替用户确认，因此正式电源库保持 0 条，不伪造“已完成导入”。
13. 输出电流不是单值字段：主规格保存默认/最小/最大电流，完整可选列表保存在 `mc_power_supply_current_options`，其中一条可标记默认。
14. 设置采用默认、全局、角色、用户四层覆盖，只允许白名单令牌和值域。
15. 权限复用广州账号；模块授权只扩展 `mc_permission_grants`，不建立第二账号。
16. F9 只读取 `naming_models`，规则和模拟结果写 `mc_` 表；不写产品和报价。
17. 匹配只依据已确认规则；未知字段不推断为通过。
18. V2 分页默认采用视口自动行数，手动条数是用户显式覆盖。
19. 抽屉宽度仅在460–620px内记忆，小屏强制全屏。
20. Excel式能力分层交付；任何批量写入必须等待字段注册、权限和服务端验证完成，不能前端伪保存。
