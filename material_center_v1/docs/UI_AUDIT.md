# Material Center V1 UI 审计

## 范围

本轮仅审计和改造 `material_center_v1`。按任务边界，不扫描或修改 `commercial_center_v1`、广州旧系统与旧数据库表结构。

## 改造前问题

- 设计变量、布局和组件样式全部集中在单个页面 CSS，无法稳定复用。
- 抽屉自行管理遮罩和 Esc，不具备统一浮层互斥、焦点返回和滚动锁定。
- 缺少浅色/深色/跟随系统主题。
- 空数据、未登录和数据不可用状态没有统一组件。
- 表格缺少键盘打开详情与分页。
- 没有组件展厅和自动静态检查。

## 本轮结果

- 新建 `ui/` 设计令牌、主题、排版、布局和组件层。
- 新建统一 InteractionManager，管理下拉菜单、弹窗和抽屉。
- 首页采用统一按钮、表单、卡片、徽章、表格、分页、状态和抽屉。
- 增加主题选择、客户展示模式、搜索清空与 300ms 搜索提交。
- 新建组件展厅，覆盖规范要求的核心控件和交互。
