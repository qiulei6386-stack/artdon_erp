# Artdon 物料中心 V1 基础说明

## 当前范围

- 独立目录：`material_center_v1/`
- 复用广州 ERP 统一登录和数据库连接。
- 只读 `bom_materials`，仅允许 `SELECT`。
- 当前展示名称、分类、品牌、型号、规格、材料牌号、单位与更新时间。
- 不展示价格和供应商，不提供新增、编辑、删除、导入或数据库迁移。

## 后续阶段

1. 物料分类与属性模板。
2. 物料永久编码、状态和版本。
3. 替代料与兼容关系。
4. 供应商、采购价和成本的分级权限。
5. BOM、报价、订单和单证引用关系。
6. 图片、附件、审计、导入校验及回滚。

任何写入能力必须先明确表结构、权限、审计与回滚方案，再单独实施。
