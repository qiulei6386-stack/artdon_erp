## 本次候选

| 项目 | 实现范围 | 隔离验证 |
| --- | --- | --- |
| 客户防串位 | 最新响应、完整资料缓存、独立属性、编辑/保存实体校验；旧响应不覆盖新编辑 | 客户详情原函数动态测试 |
| 任务按钮 | 模块动作 ID/权限；两种派工名称接真实接口；新建跟进可选择有权查看的客户 | 权限契约和动作动态测试 |
| 跟进弹窗 | 取消、关闭、替换或后次进入使旧请求失效 | 动态模型及真实 Chrome dialog/ESC/MutationObserver |
| 样品新建 | 移除两小时同款覆盖；用户+表单标记防重；参数冲突拒绝；事务失败回滚；提交后通知 | 模型及独立 MySQL 原函数/双进程竞争 |
| 样品上传 | 保存后立即绑定单据 ID；失败重试不重新建单；连续点击保护 | 动作动态测试 |
| 推广执行 | 返回真实队列受理/人工清单；不虚报发送成功，不自动重发历史失败项 | 后端状态模型和前端响应契约 |
| 推广暂停/取消 | 父任务锁与原子领取；旧保存不能覆盖生命周期；在途边界明确 | 模型及独立 MySQL 双连接真实锁等待/回滚 |
| 推广禁联/历史 | 入队和领取复核禁联策略；混合人工未完不算完成；有队列/执行历史禁止重建 | 模型及真实 SQL 禁联/混合汇总/历史保护 |
| 推广编辑 | 已知队列提前提示复制/重命名；名单请求失败或缺失不打开空编辑器 | 原入口动态测试 |
| 邮箱失效 ID | 明确选择失效/越权邮箱报错；过期会话仅回退一次；删除后选择下一邮箱 | 原函数有界查询模型 |
| 邮件慢请求 | 分别计时账号准备、筛选、计数、列表、附件、格式化、目录统计、响应准备 | 列表响应及日志数据边界测试 |
| UI 统一基础 | 建立统一规范，首批动作共用规则；未重排所有页面 | `crm-ui-contract.md` |

以上为本地候选。实际运行结果和版本同步状态以 WORK_CONTEXT 当次记录为准，不将测试模型通过表述为正式系统验收。

## 发布前必须完成

- 用户已同意将本次涉及文件的已上线未入库现状与本次修复分开记录并推送；其他文件不动。main 推送会自动部署，因此本次只同步 `codex/crm-phase1-safety-20260906` 独立分支，不合入 main、不部署。
- 所有候选 PHP 语法、JavaScript 语法、专项隔离回归、差异空白检查通过。
- 已完成原函数在独立 MySQL 上的事务/竞争验证与真实浏览器组件验证；仍须在完整隔离应用中验证有限角色账号、真实页面/API/队列全链路。SMTP 使用受控接收端，不向真实客户测试发送。
- 核对并处理全仓 CI 剩余失败，不将 CRM 专项通过当作全部检查通过；失败分类和测试复现边界见 `crm-phase1-integration.md`。
- 单独取得 CRM 正式上线批准；保存目标文件备份、数据库结构与在途队列状态，核对部署同一仓库提交，保留无关脏改动。
- 前端、API、任务/邮件/推广文件必须成套发布，避免新页面配旧响应或旧暂停逻辑。
- 发布后检查错误日志、队列行为和用户核心流程；停止上线或回退时不得自动重发邮件、清洗历史成功标记或删除业务记录。

## 本次未做

- 全量 UI 改版、主题冲突清理、所有冗余按钮清除；客户基准页与各模块迁移属于第二阶段。
- 邮件/客户提速、真实查询计划、缓存/查询优化、资源拆分、任务/拜访超过 300 条的分页属于第三阶段；本次只加计时，不声称速度已提升。
- 商机/AI/物流等尚未实现的跨模块联动属于第四阶段，不能以占位日志替代真实完成。
- 未调用真实业务保存、SMTP/IMAP、营销 worker；没有生产数据修复或历史记录清洗。
- 扫描另见任务通用客户搜索未复用客户可见范围；本次新增跟进选择器改用权限过滤的客户列表，旧接口的全量权限审查需单列跟进。

## 测试运行边界

普通 Node 动态测试从原 JS 提取方法，在假网络/DOM 中执行。PHP 专项仅提取目标函数并替换数据库、通知、邮件依赖，不加载应用启动文件；这八套轻量专项已加入现有 CI。

新增 MySQL 测试必须显式启用：仅连接已核验数据目录、socket、禁止网络监听状态和标记文件的临时独立实例，在全新空测试库建最小表结构。真实 SQL、事务和并发经过实跑；权限/通知/结构维护等周边依赖仍是替身，不验证完整应用启动或线上表结构。结束后已关闭测试实例，保留合成数据供复查。

浏览器专项使用全新 Chrome 上下文、真实 DOM/原生弹窗，但角色响应和网络数据均为夹具，周边页面是最小测试页；离线、CSP 与网络拦截共同限制外部请求。17 项通过不等于真实账号权限或完整 CRM 页面验收。两类重量级测试不自动加入普通 CI，也不调用 SMTP/IMAP 或正式业务保存接口。复现说明见 `crm-phase1-integration.md`。
