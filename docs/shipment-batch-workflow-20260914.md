# 可调整合并出货批次

## 使用入口

订单详情中的“合并出货”和“新增出货”进入装运工作台。从任意同客户订单进入后，可以选择历史未出完订单，或打开已保存批次。不同币种和发货公司抬头需另建批次；统一收货信息需要操作人核对。

1. 选单与数量：订单摘要分页展示，展开才读产品；产品可以逐项勾选和修改本次数量，“本单全部可出”范围明确，已选内容跨页保留。
2. 装箱与调整：每箱选择订单产品及数量，支持跨订单混箱。撤下整箱同时减少本批计划；拆箱重装仅解除分配，保留计划数量。数量低于已装分配会阻止保存。
3. 核对与记录：先保存再预览、签发或确认实际出货。装前改单保存新版本；历史签发单证仍可查看，并标明已替代。

## 数据规则

- 新计划保存到独立计划表，只保留轻量产品信息及数量，不复制大图片或整个历史订单快照；不修改历史出货统计或触发出货佣金。
- 保存占用可出量；其他计划和旧版出货写入入口均校验此占用。取消计划留痕并释放数量。
- 确认实际出货时，在同一事务内移除自己的占用并建立正式出货明细，保留原单价和原图。实际出货汇总沿用原系统，计划数量不会混入。
- 版本检查阻止旧页面覆盖，固定请求编号用于超时重试，批次与订单锁防止并发抢量；事务失败回滚。
- 预览只读；签发与实际出货分开。已发货批次不能普通编辑。仅管理员可更正误点确认：原明细和原图归档，恢复待装占用；关联佣金出现后续结算时阻止更正。真实退货不应使用此入口。
- 旧版出货数据及其现有统计保留，新工作台标明“已出/旧版占用”，不依据是否打印擅自重判历史实际出货。
- 原来的订单级复选功能已存在；本次补齐的是产品选择、追加订单、计划占用、装箱守恒和完整版本流程，不声称原系统完全没有复选。

## 验收与边界

合成隔离数据库覆盖追加第三张订单、增减后加回、逐产品混箱、签发后修改、重复提交、旧版本、抢占保护、失败回滚、正式出货、取消、误确认归档更正和大图片保留。独立浏览器覆盖1280/768/390宽度、选择部分数量、保存、混箱撤箱与控件布局。全量PHP/前端回归另行执行。

体积和重量仅作装载参考，不承诺几何上一定装得下。历史状态保守保留；新模块不擅自扣减其他仓储系统库存。真实页面验证与隔离验收区分记录，不能把未完成的正式点击验收记为通过。
