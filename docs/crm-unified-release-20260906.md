# CRM 本轮合并发布记录

## 已实现并进入本轮候选

- 合并第一阶段客户响应身份保护、样品提交防重、任务动作权限与真实派工入口、推广暂停/取消/领取互斥及禁联保护。
- 新建待办深红 `#991b1b` 到白色，线性 20 秒；重画接续剩余时间，结束恢复原主题/到期底色，不污染富文本。刷新旧任务不会重新播放。
- 任务、样品、拜访每页 50 条并有前后页；后台默认 300 条保持旧调用兼容；列表旧响应和旧失败不能覆盖新筛选。
- 操作区按组保留最多三个非危险主操作，其余有效操作收进“更多”，记住展开状态。已核实占位入口退出正常操作区；只读权限继续由前后端校验，不以折叠按钮代替权限检查。
- AI 未接通的报价/资料/确认草稿不能伪造生成结果；商机需求标记明确只记录需求，未接通的自动派工不可勾选，后台在保存前拒绝旧客户端请求。
- 客户搜索和联系人选择补上客户范围权限；分批出货不再把整个订单的明细混入某一批次。
- 联系人附属信息从每人三次查询改为整批三次查询；已验证的结构初始化不在同一请求重复执行；邮箱选择保存后释放会话锁；后台心跳节流；推广分页补稳定 ID 排序。
- 公共分页/更多操作使用现有主题变量；修正部分推广按钮、顶部高度和 AI 对话框强制样式。不是全站换肤，也没有删除用户主题配置。

## 本轮不能据此宣称全部完成的项目

- 邮件查询、精确计数、已发送去重仍需用真实负载验证；未声称历史慢样本 8.25 秒已消除。没有把普通发送贸然改为新的异步投递协议。
- 客户总览仍读取联动汇总；本轮批量联系人查询不等于全部客户详情按需加载。
- 报价/资料/PLM/BOM 的 AI 自动建单、商机自动建单等接口尚未实现。本轮移除误导入口并保留草稿，不能把“隐藏不可用按钮”称为“接口已接通”。

- 正式登录账号、完整同构数据和受控 SMTP 的端到端验收尚未完成；本轮未清洗历史业务数据、未重发积压邮件。
