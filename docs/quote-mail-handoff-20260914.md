# 已审核报价发送邮件

在“历史报价”或审核列表的已通过报价旁点击“发送报价邮件”。默认附 PDF，也可选择 Excel 或两者。正文是3行紧凑输入框，预填一句说明，最多2000字；签名自动带入。准备邮件后进入 CRM 当前发件账号的写信窗口，核对后必须手动点击发送。

## 测试与正式邮件

- 正式邮件：选择客户联系人，进入CRM后核对收件人、正文、签名和真实附件再发送。
- 测试邮件：选择“测试邮件”，填写一个指定邮箱（默认当前发件邮箱，可修改），主题自动加 `[测试]`。同一报价快照与签名用于生成附件，测试不会算成向客户正式发送。
- 测试草稿创建后只能向指定地址发送，不能追加抄送、密送或改成客户地址，不能移除主题测试标识。前端提示与服务器排队/实际投递前校验同时生效；更换测试邮箱请重新生成。
- 两种模式都不会因“准备邮件”直接投递。实际发送走CRM原有确认及异步队列，不新增绕过核对的直发接口。

## 发送记录

发送窗口底部展开“发送记录（我的账号）”，可刷新和查看更早记录。按当前邮件账号所属用户隔离，不扩大查看其他用户邮件权限。

每次受理发送时保存收件、抄送、密送、发件账号/名称、主题、提交时间和报价版本；实际状态沿用发送队列，显示待发送、发送中、成功、失败、取消或结果待核对。取消后再发会保留两次记录，不覆盖第一次的收件人。只创建草稿不会计为已发送。

成功时间为服务器确认发送结果的时间，不代表对方已阅读。结果不明不自动重发。旧记录缺失的发件账号、抄送/密送或用途明确显示未记录/未分类，不推断补造；新用途/发送记录采用独立新增表，不重写历史邮件。

## 发送预览

- 报价邮件窗口新增“发送预览”：先生成并保存草稿与真实附件，再查看用途、发件人、收件/抄送/密送、主题、正文/签名和审核版本；PDF可打开预览，Excel下载核对。继续只跳到CRM，不会发送。
- 不改内容再次预览复用原草稿；在报价窗口修改内容后重新预览会保留旧草稿并生成新草稿。需要持续修改同一封邮件时，进入CRM编辑。
- CRM报价邮件附件栏也有“发送预览”，读取当前编辑内容，经服务器按当前发件账号替换签名变量、检查报价版本及附件后展示，不保存、不发送。读取期间又改了内容会拒绝打开过时预览。待上传附加文件只列名称，须先保存再核对文件。
- 预览正文在独立沙箱中显示，不能执行邮件脚本或操作应用；外链图片默认不加载，可显式点击加载。预览版式是参考，最终收件端字体/排版仍可能有差异。修改后请重新预览，最后仍在CRM手动点击发送。

## 一致性和防错

- PDF 与 Excel 都由服务器读取同一审核快照生成，不使用浏览器尚未保存的价格，不重新查询最新物料成本或汇率。
- 草稿与生成请求、报价版本和发件账号绑定。重复点击/重试不重复创建；排队与实际发送前都校验审核版本及附件摘要，反审、换版、附件缺失或被替换将停止发送。
- 多联系人须明确选择；没有邮箱可先生成草稿后补填。CRM 联系人遵守客户查看权限，离职、禁联系及退订联系人不列入候选，不按相似公司名猜测关联。
- 生成附件不会发送邮件。发送继续使用既有异步队列；明确取消排队会恢复可编辑草稿及报价关联。发送结果不明时不自动重发。
- 成功发送后保留报价版本、附件名称、收件人、时间和邮件记录。重新发送须重新从报价入口生成，避免误双发。

## 文件与性能

- 真正的 PDF 文件由现有打印版式在独立普通用户 Chrome 沙箱中生成；Excel 复用现有 XLSX 导出器。原 PDF/Excel 导出入口不变。
- 不在报价列表预生成，不逐张预加载附件；只有点击才生成。生成进程限时、128MiB PHP 限额，一次只处理一个附件生成请求，忙时可重试，不抬高生产内存配置。
- 单张图片最高8MiB、1200万像素；快照最高24MiB；附件合计最高20MiB。外部图片不由服务器任意抓取，缺图/超限明确停止，不生成空文件。
- 邮件草稿内提供实际 PDF 预览和 Excel 下载核对；附件读取再次校验账号、版本及文件摘要。
- 不修改历史报价、客户资料、审核记录或既有出货数据；新增独立邮件包索引表。

## 验收范围

合成数据测试覆盖真实文件生成、单页及32行多页 PDF、XLSX 单元格/金额/公式/图片记录、实际草稿保存、幂等、不同账号/用户、审核变化、附件篡改、事务回滚、撤销及发送记录。390/768/1280浏览器模拟涵盖格式/联系人选择、失败重试、跳转和草稿元数据保留；既有发信与报价契约回归同时执行。合成 SMTP/状态测试不等于向真实客户试发，也不声明所有历史单据及 Excel 原生应用均已逐一验证。
