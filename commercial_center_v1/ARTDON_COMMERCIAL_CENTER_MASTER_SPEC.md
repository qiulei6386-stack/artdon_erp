# 01. 已确认的建设原则

## 1.1 旁路新建

商务中心采用旁路新建方式开发：

- 不重写广州原有系统。
- 不替换任何旧页面。
- 不覆盖任何旧文件。
- 不删除任何旧文件。
- 不修改旧系统公共头部、导航、登录、权限、主题和业务入口。
- 第一阶段不修改旧系统菜单。
- 所有新代码、新页面、新资源、新迁移文件全部放入独立目录。
- 新系统先通过独立网址访问。
- 删除新目录和新表后，广州旧系统仍应可以独立正常运行。

建议新建目录：

```text
/www/wwwroot/Artdon/commercial_center_v1/
```

实际路径必须以服务器检查结果为准，不得直接猜测。

## 1.2 共用广州数据库

商务中心与广州现有系统共用数据库：

```text
artdon_erp
```

但必须采用表级隔离：

- 所有新表统一使用 `cc_` 前缀。
- 第一阶段旧业务表只读。
- 不得 `ALTER`、`DROP`、`TRUNCATE`、`RENAME` 任何旧表。
- 不得给旧表增加字段。
- 不得在旧表上增加触发器。
- 不得删除或替换旧索引。
- 不得向旧业务表写入测试数据。
- 新模块测试数据只能写入 `cc_*` 表。
- 第一阶段不对旧业务表建立强制外键或级联删除。

## 1.3 现有系统继续运行

在商务中心正式验收前：

- 旧报价系统继续运行。
- 旧 CRM、BOM、PLM、派工、订单和单证继续运行。
- 新旧系统并行。
- 不做自动跳转。
- 不替换原入口。
- 不迁移或清空旧业务数据。

# 02. 系统业务定位

本系统不是单纯报价系统，也不是普通 ERP 数据看板。

系统必须完整覆盖：

1. 产品与配置维护
2. 物料与配件维护
3. 库存 SKU 管理
4. 产品发布到新加坡网站
5. 标准产品配置报价
6. 定制产品项目报价
7. 报价实时预览
8. PDF、Excel 与打印
9. 系统内邮件发送
10. 客户在线确认
11. 报价转订单
12. 客户佣金
13. 收款与尾款
14. 生产及出货进度
15. 包装资料
16. PI、CI、Packing List 及其他单证
17. 与命名、BOM、PLM、CRM、派工待办等现有系统联动

广州系统是核心业务和数据中心。

新加坡服务器只负责：

- 商品展示
- 固定套餐选择
- 购物车
- 下单
- 询价
- 订单临时缓冲
- 接收广州发布的公开商品数据

新加坡服务器不得直接连接广州数据库。

# 03. 产品业务分类

## 3.1 第三方产品

特点：

- 从第三方供应商采购
- 以固定 SKU 为主
- 通常有实际库存
- 每个产品一般只有 1 至 3 套公开销售配置
- 可以发布到新加坡网站
- 也可以进入广州内部报价

维护内容：

- 供应商
- 供应商 SKU
- 采购成本
- 入库成本
- 库存
- 销售价
- 阶梯价
- MOQ
- 交期
- 公开图片
- 公开参数
- 可销售国家
- 是否允许在线下单
- 是否只能询价

## 3.2 我司标准产品

### 有库存标准品

库存必须管理到具体配置 SKU，例如：

- 产品型号
- 功率
- 色温
- 显指
- 光束角
- 颜色
- 芯片
- 电源
- 调光方式
- 接头
- 包装版本

满足发布条件的库存 SKU 可以发布到新加坡网站。

### 无库存标准品

具备：

- 正式型号
- 产品资料
- 正式 BOM
- 标准工艺
- 可配置规则
- 标准成本

没有成品库存，需要广州业务员按客户需求配置报价。

## 3.3 定制产品

### A 级：普通选配

例如：

- 芯片
- 电源
- 色温
- 显指
- 光束角
- 蜂巢网
- 玻璃
- 防眩圈
- 调光方式

一般仍按标准品配置报价处理。

### B 级：标准品改款

例如：

- 特殊颜色
- 特殊线长
- 客户标签
- 特殊包装
- 特殊接头
- 特殊色温
- 小范围尺寸变化

需要快速工程确认。

### C 级：结构定制

例如：

- 修改尺寸
- 修改开孔
- 修改散热
- 修改光学
- 修改安装结构
- 修改外壳
- 增加新部件

必须进入工程评估。

### D 级：全新开发

完整流程：

```text
客户需求
→ 需求确认
→ 工程评估
→ 暂估成本
→ 预算报价
→ 打样
→ 测试
→ 正式 BOM
→ 正式报价
→ 转正式产品
```

首页不是普通统计看板。

目标是：

# 11. 配置规则引擎

规则类型：

## 禁止

不允许保存或报价。

## 警告

允许继续，但必须确认。

## 审批

允许保存，但必须工程或主管审批。

示例：

- 灯体最大功率
- 电源尺寸是否放得下
- 芯片与电流是否匹配
- 透镜与光束角是否匹配
- 蜂巢网与反光杯是否匹配
- 玻璃与其他配件是否冲突
- 特殊显指是否增加交期
- 特殊颜色是否增加 MOQ
- 特殊调光是否需要认证
- 国家电压与插头要求

规则不得写死在页面 JavaScript 中。
