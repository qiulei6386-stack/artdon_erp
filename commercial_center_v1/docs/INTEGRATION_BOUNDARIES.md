# 集成边界

| 系统 | V1 允许范围 | 禁止范围 | 后续接口方向 |
|---|---|---|---|
| 命名系统 | 读取 `naming_models` 标识和状态 | 回写型号、官网同步 | 经审计的服务接口 |
| BOM | 读取项目、物料、成本标识 | 改成本、物料或 BOM | 显式审批回写 API |
| PLM | 读取项目/模型状态和永久 ID | 改项目、样品、文件 | 版本化接口 |
| CRM | 按旧权限读取客户基本信息 | 写客户、联系人、跟进 | CRM 服务层接口 |
| 旧报价 | 读取报价标识和状态 | 创建/审批/删除报价 | 报价领域 API |
| 订单 | 读取订单标识和状态 | 下单、收款、出货 | 订单领域 API |
| 派工待办 | 读取任务标识和状态 | 创建、派发、完成任务 | 派工 API |
| 邮箱 | 当前只检测表与适配器可用性 | 读取正文、附件或发送邮件 | 最小权限邮件 API |
| 新加坡系统 | 仅保留边界文档与占位 | 真实网络写入、发布 | 签名、幂等、审计的跨服务器 API |

页面不得直接查询旧表；所有旧系统访问集中在 `app/Adapters/`。未接通时返回 `unavailable` 或 `not_configured`，不得伪造成功。
