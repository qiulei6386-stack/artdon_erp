# Artdon 商务中心 V1：Step 5 标准品报价完整闭环

> 状态：Step 5 已实现，等待服务器真实数据验收
>
> 实施日期：2026-07-26

## 1. 正式闭环

CRM 客户 → 报价产品库真实产品 → 物料中心配置与适配规则 → 价格策略/客户等级/阶梯价 → BOM 成本 → 金额和毛利 → 保存草稿 → 重新打开 → 提交审核。

标准品页面已移除本机 `localStorage` 假保存，改为调用 `api/v1/standard_quotes.php` 正式接口。

## 2. 数据来源

- 客户、主联系人、国家、等级、负责人、风险：`crm_customers`、`crm_contacts`
- 产品：`naming_models`
- 配置组、选项、产品允许项、冲突和审批规则：现有配置引擎 `cc_config_*`
- 价格策略：`quote_price_policies`
- 客户等级：`quote_price_levels`
- 数量阶梯价：`quote_price_tiers`
- BOM 成本：价格策略 BOM 成本字段，缺失时使用配置引擎成本
- 佣金与提醒：`quote_commission_rules`、`quote_commission_reminder_rules`

不重复维护 CRM 客户、产品或配置规则。

## 3. 价格优先级

现有数据库没有独立客户特殊价格表，因此当前顺序为：

1. 客户等级价格
2. 数量阶梯价
3. 标准价格
4. 配置建议价格
5. 无价格时阻止静默提交并显示核价提醒

独立客户特殊价格保留为未来最高优先级扩展位。手工改价受 `edit_price` 权限控制。

## 4. 页面能力

- CRM 客户和主联系人联动
- 真实产品选择
- 合法配置选择及服务端重新校验
- 添加、删除、编辑和拖动排序
- 批量数量、批量折扣
- 数量、单价、折扣、小计、交期及备注
- 20、50 项以上明细使用既有固定表头和内部滚动
- 固定汇总产品金额、折扣、运费、税费、其他费用、总金额、成本、毛利和毛利率
- MOQ、交期和佣金提醒
- 保存后生成正式报价编号，URL 保留 `quote_id`
- 可重新打开继续编辑
- 提交审核进入 `pending_approval`，生成版本、快照和日志

## 5. 安全与追溯

- API 必须统一登录。
- 所有 POST 使用独立 CSRF Token。
- 新建、编辑、改价和提交分别经过 Step 4 权限服务。
- 产品、配置、价格和成本在服务器重新读取与计算，不信任浏览器汇总。
- 保存、编辑、提交均写审计和版本快照。

本步不执行 Step 6 网站订单导入，不开发 Step 7 定制品附件，不提前接入正式 PDF/Excel/邮件和转订单。

完成服务器验收后停止，不进入 Step 6。
