# Artdon 商务中心 V1：Step 6 网站订单报价

> 状态：Step 6 已实现，等待服务器迁移与验收
>
> 实施日期：2026-07-26

## 1. 两种来源

- `website_import`：经过统一登录和权限校验，接收新加坡网站待审核订单载荷。
- `sales_proxy`：业务员选择 CRM 客户及网站产品，代客户建立网站订单记录。

新加坡实时 API 当前为 `not_configured`，系统不伪造自动同步成功；正式接收入口支持后续渠道适配器直接调用。

## 2. 幂等导入和来源快照

`012_website_quote_import.sql` 新增：

- `cc_website_order_snapshots`
- `cc_quote_unlock_requests`

渠道 + 网站订单号、渠道 + 幂等键均唯一。同一订单重复导入返回原报价，不产生第二张报价。

来源快照冻结网站订单号、CRM 客户、联系人、原始 SKU、型号、配置、数量、网站价格、运费、客户备注、附件元数据和下单时间，并保存原始载荷 SHA-256。

## 3. 默认锁定与审核调整

默认锁定：

- 产品型号
- SKU
- 配置
- 原始数量
- 网站来源行快照
- 客户原始要求

审核可直接调整审核价格、折扣、运费、交期、付款方式、贸易条款和内部备注。

修改锁定字段必须：

1. 提交解锁申请并填写原因。
2. 具有 `edit_locked` 权限的审核人批准。
3. 修改时消费一次批准记录。
4. 保存修改前后值、原因、操作人和时间到审计日志。

## 4. 状态和审核

- 导入或代建后自动进入 `pending_approval`。
- 审核调整保存为新的 `pending_approval` 版本。
- 审核可通过至 `approved`，或填写原因驳回至 `rejected`。
- 所有状态变化继续使用 Step 4 版本、快照、审批和日志。

## 5. 安全边界

- API 必须统一登录并校验独立 CSRF。
- 导入、审核、解锁、批准解锁、批准报价和驳回均受 Step 4 权限控制。
- 只写 `cc_*` 表，不修改旧报价或旧订单。
- Step 6 不执行真实转订单，不进入 Step 7 定制品和附件上传实现。

完成服务器验收后停止，不进入 Step 7。
