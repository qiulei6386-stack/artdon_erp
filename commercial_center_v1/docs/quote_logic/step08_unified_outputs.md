## 单一输出快照

预览、打印、PDF、Excel和邮件附件统一读取 `cc_quote_output_snapshots`。快照冻结报价版本、状态、客户、产品、价格、汇率、条款和金额，并保存 SHA-256；相同版本、状态和内容重复请求复用同一快照。

## 输出

- 全屏 A4 客户预览及浏览器打印。
- Google Chrome 无头模式从同一 HTML 数据生成 PDF。
- Excel 兼容 XML 工作簿从同一快照生成。
- 草稿显示 `DRAFT / 草稿`，待审核显示“待审核”，审核通过无水印。
- 生成文件登记类型、路径、文件名、MIME、大小、SHA-256、生成人和时间。

## 邮件发送

邮件附件使用输出快照对应的 PDF；保存收件人、抄送人、主题、正文、快照、附件、发送人、时间、成功/失败状态及错误。成功发送审核通过报价后进入 `sent`。
