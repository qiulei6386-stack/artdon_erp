# 0. 本轮目标

本轮将以下两项要求合并执行：

1. 对当前商务运营首页进行专业化修正。
2. 将新加坡网站传回的订单纳入广州统一订单中心管理。

在上述两项完成并通过测试后，继续向下完成更多基础功能：

- M2：产品、物料与配置中心
- M3：库存 SKU 与新加坡发布基础
- M1-D：广州现有四套正式单据格式旁路复制
- M4：标准报价工作台基础版（仅在前面全部完成且可以形成完整闭环时启动）
- M5：四套单据与报价、订单数据模型联调（条件允许才执行）

本轮不是只做静态页面。

必须按以下顺序执行：

```text
安全复核
→ M1-R 首页专业化修正
→ M1-O 统一订单与新加坡订单基础
→ M1-D 广州四套正式单据格式旁路复制
→ M2 产品、物料与配置
→ M3 库存SKU与渠道发布
→ M4 标准报价基础版（条件允许才执行）
→ 整体测试与进度记录
```

每完成一个里程碑，必须先测试、修复、更新文档，再进入下一里程碑。

# 5. M1-O：统一订单与新加坡订单基础

新加坡网站不是独立订单后台。

新加坡网站是广州商务中心的一个线上销售渠道。

新加坡传回来的订单必须全部在广州统一订单中心管理：

- 审核
- 库存
- 收款
- 拣货
- 包装
- PI、CI、Packing List
- 出货
- 物流
- 签收
- 退款或取消

## 5.2 新加坡订单两条路径

### 正常库存订单

```text
新加坡提交
→ 广州待系统校验
→ 广州待人工确认
→ 库存预占
→ 收款
→ 拣货
→ 包装
→ 单证
→ 出货
→ 回传客户进度
```

校验：

- SKU 是否有效
- 价格版本是否有效
- 库存是否充足
- 数量是否符合 MOQ
- 收货国家是否允许销售
- 运费和税费是否合理
- 是否有特殊包装
- 是否允许分批出货

### 特殊询价

出现以下情况时进入报价中心：

- 库存不足
- 数量过大
- 特殊配置
- 特殊包装
- 特殊运输
- 价格异常
- 客户要求定制

流程：

```text
新加坡询价
→ 广州标准报价或定制报价
→ PDF / 邮件
→ 客户确认
→ 转正式订单
```
