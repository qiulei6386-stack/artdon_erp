# 回滚方案

1. 停止访问独立 URL；旧菜单没有入口，因此无需改菜单。
2. 保留日志证据，确认没有正在执行的新模块请求。
3. 删除或移走独立目录 `commercial_center_v1/`；不得删除项目根其他文件。
4. 若未来已获准创建 `cc_*` 表，先备份这些表，再按 `database/rollback/001_foundation_rollback.sql` 逆序删除本次新表。
5. 回滚不得操作非 `cc_` 表、旧索引、旧触发器、旧上传和旧缓存。
6. 清除的新模块测试记录必须以 `is_test=1` 精确定位。
7. 回滚后验证旧首页、登录、CRM、命名、BOM、PLM、报价、订单、邮件和派工入口。
8. 重新核对旧表、字段、索引及触发器数量与快照一致。

本轮没有执行迁移，数据库回滚步骤为“不操作数据库”。删除新目录即可完全停用旁路模块。
